## 2024-05-24 - Avoid `JSON.parse(localStorage)` and `Date.toLocaleString` inside rendering loops
**Learning:** Found a significant performance bottleneck where `JSON.parse(localStorage.getItem(...))` was repeatedly called inside `forEach` rendering loops for list items, which forces disk access and expensive parsing on every iteration. Additionally, `Date.toLocaleString` and `Date.toLocaleDateString` were being called iteratively, which are notorious performance killers because they spin up new `Intl` formatters every time.
**Action:** Lift `JSON.parse(localStorage.getItem(...))` out of loops and pass the parsed object as a parameter. Replace `Date.toLocaleString('default', { month: 'long' })` with an array lookup `monthOrder[d.getMonth()]` (which is orders of magnitude faster). Instantiate `Intl.DateTimeFormat` once outside the loop and call `.format(date)` inside for standard date formats.
